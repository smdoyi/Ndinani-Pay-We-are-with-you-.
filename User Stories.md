Functional requirements

1. As an elderly user, I want to select my preferred language (isiXhosa, English, or Afrikaans) during setup, so that I can use the app in a language I understand.

2. As a visually impaired user, I want voice prompts to guide me through every screen, so that I can navigate the app without needing to see it.

3. As a visually impaired user, I want voice confirmation after every action (e.g. "You are about to transfer R200 to..."), so that I can verify my input before confirming.

4. As an elderly user, I want to check my account balance using simple voice or large-text commands, so that I don't need to rely on a family member.

5. As a user, I want to set up and register my account in person at a bank branch, so that I receive proper support and verification before using the app independently.

6. As a user, I want to make payments and transfers through voice-guided steps, so that I can complete transactions without third-party assistance.

7. As a user, I want to repeat or slow down a voice prompt if I don't understand it the first time, so that I don't make mistakes during a transaction.

 Non-Functional Requirements

8. As a user, I want voice prompts to respond within 1–2 seconds, so that the app feels responsive and doesn't frustrate me.

9. As a visually impaired user, I want the app to be compatible with screen readers and comply with accessibility standards , so that I can trust it works reliably with my existing assistive tools.

10. As a user, I want my voice data and personal information to be securely stored and compliant with POPIA, so that my privacy is protected.

11. As an elderly or visually impaired user, I want the app to work reliably even with a slow or unstable internet connection, so that I'm not locked out of my banking during poor network conditions.

12. As a user, I want the app's voice prompts to be clear and use simple, everyday language, so that I don't get confused by technical or banking jargon.
